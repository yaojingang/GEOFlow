# 链接池与提示词实时测试

适用于包含链接池和提示词测试功能的开发版本。内链投放位于“分发管理”，提示词测试位于“AI 配置器”的提示词编辑页。

## 升级和运行条件

本轮新增以下 3 项维护模式迁移，已纳入升级计划：

- `2026_09_30_122120_create_link_pool_tables`
- `2026_09_30_130000_create_link_pool_theme_adaptations`
- `2026_09_30_202116_add_external_targets_to_link_pool`

升级前备份数据库、主题与配置，排空旧 worker，按项目升级流程执行迁移并重新构建前端资源。队列需处理 `default` 和 `theme-replication`，调度器按小时清理超过 90 天的链接池历史记录，当前推荐批次继续保留。

主题自动适配默认保持关闭。确认 Web、队列和升级进程共用主题存储及升级锁目录后，设置 `GEOFLOW_LINK_POOL_THEME_SHARED_STORAGE=true`。`GEOFLOW_LINK_POOL_THEME_READBACK_BASE_URL` 应指向这些进程能访问的可信 GEOFlow HTTP 入口，只包含协议、主机和可选端口。入口不得包含路径、查询参数或凭据，回读流程会验证当前站点的渲染结果。配置完成后刷新配置缓存并重启相关 worker。

提示词测试使用共享缓存保存运行状态和取消请求，状态在创建后两小时过期。Web 服务需允许流式响应，并同时处理状态和停止请求；本地开发 Compose 使用 4 个 PHP 服务进程。反向代理的响应缓冲及超时应与部署中的流式处理设置一致。

## 内链投放

1. 在“站点设置”选择来源站点，检查当前主题是否支持推荐区。已支持的主题可直接开启推荐；需要适配时，由超级管理员执行适配、检查回读结果后开启。适配失败可查看原因并重试，已发布适配可回滚。
2. 在“链接库”添加文章目标或导入外部链接。导入先预检，核对站点范围与错误行后确认。外部目标只有通过健康检查后才具备投放资格。
3. 在“投放活动”配置来源站点、目标、分类、关键词和展示数量，使用推荐预览检查选择结果，再发布活动。
4. 在公开文章页检查推荐内容和实际目标地址，在“效果看板”查看有效链接及统计。来源站点暂停、推荐关闭、活动暂停或目标下线后，公开输出按当前资格及时过滤。紧急停用会关闭全部站点的推荐输出。

站点默认展示 4 条推荐，可设置为 1 至 6 条，默认轮换间隔为 24 小时。推荐批次保留候补位置，目标失效时可由仍具备资格的候补补位。有效链接统计遵循公开页面的展示上限与去重规则。

三类统计分别记录：服务端实际输出推荐 HTML、浏览器确认推荐可见、浏览器上报点击。停用 JavaScript 时，推荐内容仍可显示，浏览器可见和点击事件无法上报。爬虫访问与读者事件分别处理；这些数字反映可观测事件，不代表搜索引擎排名或转化结果。

## 提示词实时测试

1. 打开一个已创建的提示词，在编辑器中调整内容。测试读取当前草稿，提示词保存仍由编辑页的保存操作完成。
2. 选择 1 至 5 个知识库，手动输入标题或从标题库选择，并选择可用的生成模型。诊断模型可单独选择，默认沿用生成模型。
3. 开始测试，查看检索状态和流式正文；需要中止时点击停止。已发出的模型请求受提供方超时影响，停止请求会在处理流程恢复控制时生效。
4. 正文完成后检查诊断，点击原文定位核对具体建议。可以调整草稿再次测试、复制正文，或对保留的正文重试诊断。

每位管理员同一时间仅运行一个提示词测试。模型权限、运行状态和配额会在调用时重新检查，生成和诊断分别记录用量。模型失败、权限变化、额度不足或状态过期时，页面显示对应原因；恢复后由管理员重新发起测试。
