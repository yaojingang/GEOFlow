# 专题功能与模板管理

实现依据：[专题频道方案 v2.5](../GEOFlow_Topic_Channel_Universal_Proposal_v2.5.md)及[交互原型](../prototypes/topic-channel-v2.4/README.md)。本轮更新尚未正式发布。

## 管理与生成

内容管理中的文章列表右侧提供专题入口，可新建、批量新建、编辑、审核、发布、撤回和恢复专题。专题复用已有文章，可分组排序，设置匹配与排除规则，组织导读、摘要、关键要点、标签和常见问题。

专题任务复用标题库、模型配置和任务调度。可以通过 CSV 导入同名不同范围的标题，设置逐行范围和模板，保存为独立标题资产；任务支持生成、定期维护、暂停、恢复、失败重试及生成后处理方式。

AI 基于本站合格公开来源生成，并执行独立事实校验。事实引用、人工修改和审核版本分别保留；来源失效、内容撤回或配置变化时重新核对发布资格。

## 前台与搜索

专题列表和详情提供默认卡片、阅读指南和时间汇总三种布局。首页、导航与文章反向链接可调用专题，详情展示结构化摘要、来源、日期、标签及可选编辑评分。编辑评分不会输出用户聚合评分标记。

规范地址、分页、过滤页索引策略、Sitemap、CollectionPage、ItemList 和 BreadcrumbList 与页面内容保持一致。时效标题依据实际维护结果更新；地址变更提供预检与确认，旧地址直接跳转当前合格公开地址。

## 模板库

网站设置置顶当前模板，默认展示 6 套精选模板，提供我的模板和已归档分区、搜索、分页、静态缩略图及单卡片预览和启用操作。

批量归档保留模板文件和历史绑定，可在归档分区恢复；当前使用模板和系统默认前台受保护。版本组使用明确映射，公共默认配置为空，部署可在 `config/theme-library.php` 配置自己的模板家族。

内置和安装模板的管理员预览涵盖首页、分类、文章、专题列表、专题详情及专题空态。当前定制修订使用对应 HTML 和资源；其他模板使用自己的预览上下文。预览不会切换正式模板、提交表单或增加文章阅读计数。

## 升级与验证

本轮新增 7 项迁移均采用维护模式。升级前备份数据库、模板及配置，构建前端资源，进入维护窗口，停止旧 worker 与 scheduler 并排空在途请求；执行迁移后再启动新进程。遵循既有安全升级确认流程，验证专题入口、当前模板和生成任务后退出维护模式。新增专题迁移涵盖内容版本、来源关系、路径、执行和审核记录；存在专题数据时，回退迁移会保护已保存内容。完整数据恢复会将专题生成记录和导入批次的全部状态纳入隔离清单，保持暂停并逐项核验；详细边界见[恢复后的业务对账说明](../api/recovery-reconciliation.md)。

相关验证位于 `tests/Feature/Topics`、`tests/PostgreSQL/TopicConcurrencyTest.php`、`tests/Browser/topic_workflow_smoke.py`、专题 JavaScript 测试及 `AdminThemeLibraryTest.php`。浏览器测试使用隔离数据库和演示账号，不操作真实站点内容。

GEOFlow Skill 提供专题操作和专题模板设计、复刻、修改的能力发现与工作流说明。远程管理能力遵循实例能力交集；草稿预览、模板安装、启用和远程发布分别处理，不能从预览能力推断发布授权。

GEO 观测工具提供离线采样计划与报告，不自动访问外部平台：

```bash
php artisan topics:observations-report --template --output=/path/to/new-plan.json
php artisan topics:observations-report /path/to/observations.json --output=/path/to/new-report.json
```

真实搜索平台效果需要另行采样与验证；本轮功能测试不能替代外部效果证据。
