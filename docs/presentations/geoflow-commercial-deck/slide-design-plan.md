# GEOFlow 商业演示稿页面设计计划

## 全局设计系统

- 风格来源：`/Users/laoyao/Desktop/index.html` 的 Apple Keynote Flat
- 色彩：纯黑 `#000000`、纯白 `#ffffff`、石墨黑 `#1d1d1f`、中性灰 `#6e6e73`、Apple 蓝 `#0071e3` / `#2997ff`
- 字体：`SF Pro Display / PingFang SC` 作为展示字体，`SF Pro Text / PingFang SC` 作为正文，`SFMono` 作为元信息
- 形态：零圆角、细线、无厚重阴影、超大标题、克制留白
- 普通页固定锚点：左上 GEOFlow 锁定字样；右上 `产品演示 · 2026.09`；标题位于统一的 `--title-top`；左下来源；右下页码
- 页面节奏：P01 黑 / P02 白 / P03 黑 / P04—P08 白 / P09 黑 / P10 白 / P11 黑 / P12 白
- 交互：键盘、滚轮、触摸、隐藏十点 Dock、右上隐藏全屏控制、哈希页码、打印模式
- 文本/图形比例：4 张文本模块页、1 张流程图页、5 张真实截图页、2 张价格与收束页

## 图形模板声明

- P03 使用 `three-stage` 模板的扩展五阶段流程，因为源码给出明确的五段业务链路；扩展保留节点、连接、方向和反馈路径，避免把流程画成无连接卡片
- P12 使用 `roadmap` 的三阶段水平路径，节点与连接线保持可见
- 其余概念页使用文本模块；截图页依赖真实产品画面，不增加无来源数据图表

## 截图校验标准

- 1440×900：所有标题单行，截图完整可辨，底部元信息不遮挡画面
- 1280×720：P04、P05、P07 三图页不发生截断；P11 价格数字与合同清单同时可见
- 1280×600：字体与间距按短高度规则缩放，装饰线可隐藏，正文仍保持完整
- 390×844：双列与三列内容改为紧凑网格或纵向栈，不允许内部滚动
- 导航：Dock 默认隐藏、右侧悬停出现、十点窗口跟随、`F` 与右上热点控制全屏
