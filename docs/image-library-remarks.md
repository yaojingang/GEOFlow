# 图片备注与智能配图

在图片库详情页为图片维护备注，写明画面主体、场景和适用内容。备注保存在现有标签字段中，供正文生成选图使用。未填写备注时，系统使用可读文件名。

任务启用图片库且配图数量大于零时，正文提示词最多提供最近的 40 张候选图及备注。自定义提示词可使用 `{{images}}`，缺少该变量时系统会补充配图上下文。

模型应原样复制候选图 URL，并在相关段落后插入 Markdown 图片。系统只接受该图片库的已知 URL，去重后按正文顺序保留，图片数量同时受任务设置和 5 张硬上限约束。模型未选图时，系统按任务数量从图片库抽取并分段插入。

配图数量为零时，不提供候选图上下文，生成正文中的候选配图会被移除。备注功能沿用图片库现有权限，任务的质检、停止与发布意图规则继续生效。

图片识别复用与正文呈现相同的 CommonMark 解析器，引用式、折叠式及简写式图片也受相同数量与 URL 约束。普通正文、加粗和代码片段保留源 Markdown 语义。


选图复用正文页面的前处理，嵌套图片按实际显示的外层图片参与选择。拒绝的图片以标准空格实体隔开相邻 Markdown，避免删除后形成新图片或改变代码缩进。正文渲染、摘要和平台纯文本复制均显示正常空格。回退插图后再次按实际渲染结果校验图片 URL、数量、去重及返回的图片列表。
