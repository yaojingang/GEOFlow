# GEOFlow v3.0.0

GEOFlow 3.0 把可信知识、AI 内容生产、质量审核、多站点分发和数据分析整合到统一的 Admin UI V3，并完成独立更新工具、安全发布链路和管理员 AI 模型隔离。

## 重大变更

- 本版本及后续仓库修订采用 AGPL-3.0-only；已经按 Apache-2.0 发布的历史版本继续适用原许可证，闭源修改、白标、OEM 和专有集成可申请单独的商业许可。
- 独立 GEOFlow Updater 成为网站更新、完整备份和恢复点回滚的执行边界，旧应用内执行器退出运行配置；更新、备份和回滚需要管理员密码及验证器生成的 6 位授权码。
- AI Workspace 调整为后台图文帮助助手，旧版 Run、Plan、Approval、Capability 和 Trace 工作流停止接收新请求，历史会话与审计记录继续保留。

## 新增

- 统一 Admin UI V3 的侧栏、顶栏、表单、对话框、响应式布局、无障碍状态和 PWA 安装体验，并将图标、字体与页面资源改为本地加载。
- 上线系统知识与图文帮助，内置 15 个主题、24 张脱敏截图和 72 条固定评测，回答中的功能入口按当前管理员权限生成。
- 上线文章 AI 质检、三层知识召回、受治理原子事实和自动优化闭环，质检结果、人工放行、输入快照、证据来源和策略变化全程留痕。
- 增加托管渠道站点、Chrome 运营助手和人工发布闭环，覆盖子域名生命周期、发布配额、技术预检、设备配对、草稿填充、执行凭证和人工确认。
- AI 模型配置增加所有者与访问范围，普通管理员可维护个人模型，也可使用超级管理员明确共享的用户内容模型；异步 AI 任务统一携带执行身份并记录用量归属。
- 扩展标题库、任务回收站、Markdown 批量导出、API v1 和 GEOFlow CLI，标题库支持最高 10 万条的分批生成、恢复、取消、重试和去重。

## 安全与可靠性

- 稳定版更新检查改为读取 GitHub 最新正式 Release 附带的 `version.json`，开发分支中的版本变化不会再触发正式版更新提示。
- 发布、分发、人工操作和文章修改共用质量与风险门禁，并加强出站请求、敏感信息脱敏、API 幂等、并发锁、恢复任务和知识引用保护。
- `league/commonmark` 升级至 2.10.0，同时更新兼容的 Nette 依赖，修复 Markdown 解析相关安全公告。

## 升级提示

- 升级前备份 PostgreSQL、`.env`、上传目录和 `storage`，进入维护窗口并排空旧进程，再执行数据库迁移、前端构建和应用、队列、调度器及 Reverb 重启。
- 从早期 2.x 版本升级时，继续执行 `php artisan geoflow:managed-images:readiness` 与 `php artisan geoflow:security-audit`；使用 Chrome 运营助手的环境还需同步更新扩展。
- 托管站点默认关闭，完成泛 DNS、通配符 TLS、可信代理和 Nginx 三入口配置后再启用。
- 本版本使用 GEOFlow Updater v0.3.0、内置 GEOFlow CLI 0.2.0 和 Chrome 运营助手 0.1.0；Updater v0.3.0 必须绑定本次 Core 最终提交与 app/web 镜像摘要，并通过 linux/amd64 与 linux/arm64 真实宿主演练。

完整变更见 [中文更新日志](../CHANGELOG.md) 和 [English changelog](../CHANGELOG_en.md)。
