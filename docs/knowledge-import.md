# 知识文档导入

知识库和企业知识都支持 TXT、MD（含 `.markdown`）、DOCX、PDF 和 PPTX。PDF 与 PPTX 需要包含可提取的文本；扫描件、纯图片 PDF 和纯图片演示稿需先进行 OCR 文字识别。旧版 DOC、PPT 请先另存为 DOCX、PPTX，再上传。

每次最多上传 10 个文件，单文件和本次文件合计均不超过 8 MiB。提取后的正文及合并后的内容也各有 8 MiB 上限。知识库单文件导入保留原文件类型；手动文字与文件混合、多文件合并继续保存为 Markdown。企业知识按文件保存原始来源和类型。

PDF 使用独立的 PHP CLI 子进程解析。每个子进程设置 `memory_limit=128M`，父进程在约 10 秒的运行上限后终止超时解析。128 MiB 限制覆盖 PHP 计入的内存分配；操作系统进程的实际常驻内存还包含运行库开销。解析同时限制单次过滤器解码结果为 16 MiB、累计解码结果为 32 MiB，并拒绝达到截断探测边界的流。服务器需安装 PHP CLI、允许 `proc_open`，并随应用保留 `scripts/extract-knowledge-pdf.php`。无法启动、超时或超出限制时，页面会返回错误。

PPTX 按演示稿中保存的幻灯片顺序提取正文。压缩包最多 2,048 个条目，单条目展开不超过 16 MiB，所有条目的展开大小合计不超过 32 MiB，压缩比不超过 100。XML 文档类型和实体、外部关系、逃逸压缩包的关系路径及无效结构都会被拒绝。包含外部链接关系的演示稿需要先移除这些关系或重新导出。

PPTX 最多保留 2,048 个幻灯片 ID；每个关系文件最多 2,048 条关系，整包最多 16,384 条。所有幻灯片合计最多 100,000 个文本节点，空节点和短文本节点也计数。幻灯片与关系 ID 最长 255 字节；压缩包路径及关系的 Target、Type、TargetMode 属性最长 1,024 字节，路径在规范化前最多 64 段。相对关系路径与所在目录拼接后也需满足路径限制。上述结构预算在数组保留和路径分段前检查，正文继续受 8 MiB 上限约束。

文件校验或解析失败时，本次已上传的来源文件会被清理，知识库和企业知识记录不会创建。部署时还需确认 PHP、反向代理的上传限制允许本次请求大小；应用中的 8 MiB 上限持续生效。
