# GEOFlow 更新日志

该文档记录公开仓库可见功能的持续更新。后续每次推送到 GitHub 时，同步更新本文件和英文版 `CHANGELOG_en.md`。

## 2026-09-03

### 管理员 AI 模型隔离与共享

- AI 模型配置新增明确所有者和访问范围；普通管理员可以维护个人模型，也可以按管理员设置使用指定超级管理员共享的用户内容模型，自动选模遵循个人模型优先、共享模型兜底。
- 新建普通管理员默认使用独立配置，历史管理员和模型提供显式回填命令；共享关闭、账号停用、角色变化或模型归档会递增访问版本，并阻止后续外部调用和失效结果落库。
- 内容生成、标题、文章优化与质检、Knowledge Fact AI 生成、企业知识、URL 导入、AI Workspace、API、CLI、队列和恢复任务统一携带执行身份，模型用量按配置所有者、执行管理员和业务来源记录。
- AI 搜索源、系统采集、全局 Embedding、知识切片和索引配置仅限超级管理员管理；普通管理员的实时向量查询使用个人或共享的兼容模型，缺少兼容模型时自动使用关键词检索。
- 共享模型页面和接口只返回脱敏元数据，密钥查看、配置修改、连接测试和删除权限继续归配置所有者；新增 Shadow 对比报告、访问面架构门禁和分阶段发布手册。
- 手动入队和活动任务修改会同时校验操作者与冻结执行身份；共享模型允许并发调用且配置变更保持独占，用量账本在外呼前记录不可变起始事件并自动对账失联结果，历史回填覆盖全部异步 AI 生命周期。
- 升级 `league/commonmark` 至 2.10.0，并同步更新兼容的 Nette 依赖，修复最新安全公告涉及的 Markdown 解析风险。

- 新增原子质检、切片质检、知识库质检三种召回方式，任务设置与单篇文章编辑页共用可用性判断、默认优先级、继承与覆盖规则；原子质检在准备度满足时优先选中。
- 建立召回准备度、服务代次、来源依赖账本和不可变执行快照，质检记录保存请求方式、实际方式、策略版本、来源哈希与审计信息；知识、模型、提示词、正文和 rollout 变化会选择性使旧结果失效并触发对账。
- 完成受治理原子事实库的生成、审核、版本发布、稳定键、证据重连、类型化比较和活动版本服务能力；原子路径覆盖确定性事实，未覆盖或歧义主张继续进入切片检索。
- 加固高风险知识审核、宽范围正文证据预算、提示词注入隔离、跨令牌 API 幂等、并发策略版本校验、分发门禁快照和知识库引用删除保护。
- 扩展管理端知识库导航、原子事实工作台、AI 模型诊断和六种语言文案，并增加历史数据回填命令、Docker 队列配置、Laravel 与 JavaScript 回归测试及评测报告。

- 新增文章 AI 质检自动优化闭环：管理员可选择达标、80 分优秀或 90 分优秀目标，系统按轮次生成候选修改、重新质检、展示分数与变更记录，并支持应用、取消、回滚和异常任务对账。
- 提升 AI 质检稳定性与可解释性：优化长文检查、证据定位、结果校验、评分与失效策略，补充专用队列、健康检查、额度控制和版本化提示词，任务页可配置自动优化策略。
- 统一后台高风险操作交互：文章、任务、模型、素材库和知识库等页面共用操作确认对话框，明确操作对象、影响范围、输入校验、处理中状态与失败恢复提示。
- 完善 Admin UI V3 页面体验：文章质检结果支持折叠，顶栏与页面身份更清晰；每个后台页面底部统一展示版本、更新日志、许可证、版权、作者 X 主页、GitHub 仓库和帮助入口，并兼容短页面贴底与移动端换行。
- 扩展 API v1 与 GEOFlow CLI 的文章 AI 优化能力，并为 Docker 部署补充质检与优化队列的超时、重试、健康检查和 Worker 配置。

  - 系统知识库拥有稳定绑定、官方版本、健康状态、受控二次编辑、修订恢复和幂等同步；应用与数据库共同阻止删除，索引故障时继续使用正文回退。
  - 帮助检索只读取系统知识，支持复杂问题的多章节证据、短追问上下文、24,000 字符总预算、结构化来源与权限过滤后的功能入口。
  - 新增 24 张脱敏 WebP 后台截图、私有存储、哈希校验、不可变替换版本、图库管理、相关性选择和历史固定回放；中文回答单次展示 0 至 3 张强相关图片。
  - 新增 72 条固定问答评测、全后台路由分类、知识和图片清单门禁，以及未过期历史引用保护的媒体清理策略。
- 完成独立更新工具 C 批切换：
  - 独立更新工具成为网站更新、完整备份和回滚的唯一执行边界；旧计划、文件覆盖、单文件恢复、重试和人工失败标记入口已移除。
  - 旧运行与备份表继续保留，更新中心按最近 90 天和归档视图提供只读审计查询。
  - 网站发起更新、备份或回滚时需要管理员密码与验证器生成的 6 位授权码；更新工具在宿主机以独占锁持久化已消费时间步，阻止授权码重放。
  - 旧更新队列容器与 Horizon supervisor 已退出运行配置；兼容 tombstone 任务只把遗留队列记录标记为已停用，不执行文件、数据库或容器变更。
  - 出站响应总上限迁移到独立配置，旧执行器配置已清理；发布清单新增 amd64 与 arm64 真实宿主演练门禁。
- 完成独立更新工具 B 批接入：
  - 系统更新中心新增安全更新、完整备份、环境验收和恢复点一键回滚入口，敏感操作要求超级管理员确认当前密码。
  - 页面展示持久化操作编号、当前阶段、阶段结果和最近恢复点；操作执行期间自动刷新状态并阻止并发提交。
  - 网站通过固定类型的本地 Unix socket API 发起操作，接口不接受任意命令或文件路径。
  - 更新工具在迁移和版本切换前备份 PostgreSQL、完整站点存储、持久化 Redis 数据、环境配置、版本文档和受管部署状态；受保护阶段失败时自动恢复并验收。
  - 恢复点在写入后记录摘要、大小、权限和属主，恢复前完成全量校验，默认保留最近 5 个。
  - 操作中断后由持久化 recovery_required 状态和跨进程锁协调恢复；新旧执行器双向检查运行状态，避免后台入口和队列任务交叉执行。
  - 管理员密码不进入审计载荷或失败回填，代理异常仅写入服务端日志；应用侧严格校验 Unix socket 响应结构和长度。
- 新增独立更新工具 A 批接入：
  - 系统更新中心新增 GEOFlow Updater 连接状态、环境诊断摘要、已签名安装包准备与私有下载入口。
  - 安装包经过内置 2/3 离线可信根、targets 角色签名、平台、大小和 SHA-256 校验，下载请求统一经过出站安全网关。
  - 安装包私有暂存状态包含签名有效期并在下载时重新校验文件类型、路径、大小和摘要，符号链接、过期状态和被修改的文件会被拒绝。
  - 网站仅通过带实例令牌的本地 Unix socket 读取更新工具状态，不挂载 Docker socket。
  - 首次托管接管命令会加载站点与签名发布两份环境文件，在挂载同一数据库目录前显式停止标准生产项目，并提示排空队列和预留维护窗口。
  - A 批建立独立工具的安装、信任和连接基础，B 批在此基础上接入事务操作。

- 新增文章 AI 质检工作流：
  - 任务新建与编辑支持默认关闭的 AI 质检开关，可选择质检方案、执行模型、自动通过分和人工放行最低分。
  - 每篇启用质检的文章先结合知识库、版本化广告规则和发布语境完成异步检查，由后端固定规则计算总分与四项分数。
  - 通过结果继续原审核与发布周期；待复核、阻断、异常和过期结果保留为草稿，并统一阻止本地发布、站点分配、人工发布和渠道分发。
  - 文章列表与详情展示状态、分数、结论、问题颜色、原文定位、证据、法规依据、修改建议和历史记录，并提供重检与审计化人工放行。
  - 文章、任务策略、提示词、模型、知识切片和法规版本变化会使旧结果过期，调度任务负责补偿重检。
  - 长文章按分段续派独立队列任务，每个模型的结构化请求与 JSON 回退共享单次时间预算；补偿扫描隔离单篇配置异常并使用游标续派，避免一篇文章阻塞后续质检。
  - 质检执行加入 180 秒端到端截止时间、专用在线与回填队列、超时抽样降级、类型化供应商故障和 Worker 健康检查；失败记录保持“未评分”语义，并给出可执行的重试建议。
  - 新增可灰度启用的 `fast_v2` 紧凑执行、稳定证据键、评分 v2 影子评测、离线与真实模型黄金集命令，以及带事故冻结和恢复报告的分级发布门禁。
- 统一 Admin UI V3：
  - 后台主要页面统一使用新的侧栏、顶栏、导航、表单、对话框和响应式布局，补充最近访问、侧栏宽度调节、键盘操作、移动端与无障碍状态。
  - 图标、字体与页面资源改为本地加载，首屏状态和页面切换经过稳定性检查，减少闪烁、布局跳动与外部资源依赖。
- 调整 AI 工作台边界：
  - 3.0 的 AI 工作台定位为后台帮助助手，使用本地帮助目录、当前管理员权限和一次对话模型调用回答系统使用问题，通过 SSE 返回真实连接状态与流式正文。

  - 支持在托管根域下分配子域名、管理站点生命周期、分配文章、控制发布配额与间隔，并提供暂停、维护、归档、索引和失败冷却状态。
